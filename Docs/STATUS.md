| `/api/materials`, `/api/materials/:id/stock` | GET |

| `/api/face-control/events` | GET |
| `/api/face-control/login` | POST |

Мутации живут в памяти вкладки (MSW в service worker) и сбрасываются
перезагрузкой — смена статуса, комментарии и решение по макету не переживают
рефреш.

## Чего в прототипе нет вообще

- Backend, БД, Redis, реальный API — только моки
- Аутентификация и авторизация (роли переключаются тумблером в шапке)
- Загрузка файлов и макетов в S3 — плейсхолдеры
- Генерация PDF — кнопки есть, файлов нет
- Онлайн-оплата — кнопка выключена, провайдер не выбран (🔴 Q5)
- Face Control — мок-события, без вендора (🔴 Q2)
- Расчёт ЗП, амортизация, налоги, логистика по картам
- Storybook — в `DESIGN_SYSTEM.md` упоминается, в репозитории не настроен
